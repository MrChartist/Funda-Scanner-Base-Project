# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, personal attacks,
discriminatory language and unwelcome sexual attention are not tolerated, in issues,
pull requests, discussions or any other project space.

## Enforcement

Maintainers may edit or remove comments, commits and issues that violate this code, and
may temporarily or permanently ban contributors for harmful behaviour. To report a
problem, contact the maintainer through their GitHub profile
([@MrChartist](https://github.com/MrChartist)). Reports are handled confidentially.

This text is adapted from the Contributor Covenant, version 2.1, available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
