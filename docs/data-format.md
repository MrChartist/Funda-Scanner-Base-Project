# Data format

Funda Scanner can load your own fundamentals (**Import your data**, in the banner or on the Screener).
Files are read in your browser and are never uploaded. You are responsible for the accuracy and
licence of any data you import.

You can drop several files at once. They are joined by `symbol`:

| File | What it holds | Template |
|------|---------------|----------|
| Company list (`companies.csv`) | One row per company: name, sector, type, market inputs | [`companies-template.csv`](../public/sample-data/templates/companies-template.csv) |
| Annual statements (`annual.csv`) | One row per company and financial year | [`annual-template.csv`](../public/sample-data/templates/annual-template.csv) |
| Quarterly results (`quarterly.csv`) | One row per company and quarter | [`quarterly-template.csv`](../public/sample-data/templates/quarterly-template.csv) |
| Shareholding (`shareholding.csv`) | One row per company and quarter | [`shareholding-template.csv`](../public/sample-data/templates/shareholding-template.csv) |
| One-row snapshot (CSV or JSON) | The original 13-column format, one row per company | [`fundamentals-template.csv`](../public/sample-data/fundamentals-template.csv) |
| Funda Scanner dataset (JSON) | Everything above in one file; the format the app exports | — |

The file kind is recognised from the column headers (or the JSON shape), not from the file name.
Statement rows need a company list, a snapshot or a dataset file that names the symbol; rows for
other symbols are skipped with a warning.

The template rows describe a fictional company called `EXAMPLE`. Replace them with your own data.

## Units

| Kind | Unit | Example |
|------|------|---------|
| Money totals (revenue, profit, assets, cash flow, market cap) | ₹ crore | `1760` means ₹1,760 crore |
| Per-share values (price, dividend per share) | ₹ per share | `4.5` |
| Shares | crore shares | `10` means 10 crore shares |
| Percentages | percent numbers | `55.2` means 55.2%, not `0.552` |

If your statement CSVs are in ₹ lakh, ₹ (rupees) or ₹ million, choose that unit in the import
dialog. Money totals in the four CSV files are then converted to ₹ crore and the dataset notes say
so. Per-share values, share counts and percentages are never converted. Dataset JSON and snapshot
files are always read as ₹ crore.

## Values

- **Missing is never zero.** Blank, `-`, `—`, `NA`, `N/A`, `null`, `none` and `nil` mean "not provided".
  The only figures treated as 0 when missing are other income, exceptional items, non-controlling
  interest, lease liabilities and current investments; the company page lists every such assumption.
- Numbers may use Indian or international grouping (`1,20,000`), `%`, `₹`, `Rs.`, a trailing `Cr`,
  accounting negatives `(123.4)` and the minus sign `−`.
- Anything else that is not a number is treated as missing and reported as a warning.
- Text cells are data only. Nothing in a cell is ever evaluated.
- Lines that start with `#` are comments and are skipped. A first line such as
  `# Fictional sample data generated by Funda Scanner …` marks the files as fictional sample data.
- Dates: `YYYY-MM-DD` is preferred. `31-03-2026` and `31/03/2026` (day first), `31 Mar 2026` and a
  month alone (`Mar 2026`, meaning the month end) are also read.
- Fiscal years: `2026`, `FY26`, `FY2026` and `2025-26` all mean the year that ended in 2026.

## Company list columns

| Column | Required | Notes |
|--------|----------|-------|
| `symbol` | **Yes** | Upper-cased. Aliases: `ticker`, `nse_code`, `code` |
| `name`, `sector`, `industry` | No | The name defaults to the symbol; the sector to "Unclassified" |
| `isin` | No | Display only. A value that does not match `IN` + 9 letters or digits + a check digit is kept with a warning |
| `company_type` | No | `non_financial`, `bank`, `nbfc`, `insurance` or `other_financial`. When blank it is inferred from the sector |
| `statement_basis` | No | `consolidated` (default) or `standalone` |
| `fy_end_month` | No | 1–12 or a month name; default 3 (March year end) |
| `price` | No | Reference closing price in ₹, not a live quote |
| `price_date` | No | Shown exactly as supplied; never filled in by the app |
| `shares_outstanding`, `face_value` | No | Crore shares; ₹ per share |
| `market_cap` | No | ₹ crore; used only when price × shares is not available |
| `source_note` | No | Free text about where the data came from |
| `pe`, `roce`, `roe`, … | No | Snapshot ratios, as in the one-row format; values derived from statements take precedence |

## Annual statement columns

`symbol` and `fiscal_year` are required (or `period_end`, from which the fiscal year is derived).
Optional row columns: `period_end`, `flags` (`restated` and/or `transition`; growth across a flagged
year is not calculated) and `statement_basis`. Every other column is a field below, by its name, its
label or its metric id (for example `revenue`, `Revenue from operations` or `sales`).

| Field | Notes |
|-------|-------|
| `revenue`, `operating_expenses`, `cogs`, `other_income`, `depreciation`, `finance_cost`, `exceptional_items`, `pbt`, `tax_expense` | Profit and loss, ₹ crore. Operating expenses exclude interest and depreciation |
| `net_profit`, `net_profit_owners` | PAT including the minority share; PAT attributable to owners |
| `dividend_per_share` | ₹ per share for the year, adjusted to the current face value |
| `interest_expended`, `provisions_contingencies`, `advances`, `gross_npa`, `net_npa` | Lenders only |
| `equity_share_capital`, `other_equity`, `non_controlling_interest`, `borrowings_non_current`, `borrowings_current`, `lease_liabilities`, `trade_payables`, `total_current_liabilities`, `total_assets`, `net_fixed_assets`, `inventories`, `trade_receivables`, `cash_and_bank`, `current_investments`, `total_current_assets` | Balance sheet at year end, ₹ crore |
| `shares_outstanding_ye` | Crore shares at year end, adjusted for later splits and bonus issues |
| `cfo`, `capex`, `equity_issuance` | Cash flow, ₹ crore. Enter capital expenditure as a positive number |

The required fields for a non-financial company are revenue, operating expenses, depreciation,
finance costs, profit before tax, tax, net profit, equity share capital, other equity, both
borrowings, total assets, cash and bank, cash from operations and capital expenditure. Missing ones
are listed in the company's data health, never invented.

## Quarterly and shareholding columns

- Quarterly: `symbol`, `period_end` (the last day of the quarter), `revenue`, `operating_expenses`,
  `depreciation`, `net_profit`, `net_profit_owners`. Quarters are matched by date (± 15 days), never
  by label or position.
- Shareholding: `symbol`, `period_end`, `promoter_pct`, `promoter_pledged_pct` (the share of the
  **promoter** holding that is pledged, not of all shares), `fii_pct`, `dii_pct`, `num_shareholders`.

## Funda Scanner dataset (JSON)

The canonical format: `{ "schema": "funda-dataset", "version": 1, "meta": { … }, "companies": [ … ] }`,
with the same field names as above (see `src/lib/contracts/dataset.ts`). Series are stored oldest
first. Use `null` for missing numbers. Exporting and importing a dataset gives back the same data.
A file whose `meta.isSynthetic` is `true` stays labelled as fictional after import.

## One-row snapshot

The original format: `symbol`, `name`, `sector`, `industry`, `market_cap` (₹ crore), `price` (₹),
`pe`, `eps`, `price_book`, `roe`, `roce`, `debt_equity`, `debt_ebitda`, `dividend_yield`,
`sales_growth`, `profit_growth`, `fcf_yield`. As JSON: an array of objects or `{ "rows": [ … ] }`.
Header matching ignores case, spaces, punctuation and unit suffixes, so `ROCE (%)` and `roce` are the
same column. A snapshot has no statements, so history-based metrics, checks and scores are unavailable.

## Checks

The import report lists every problem with its file, row and symbol. Errors block the import;
warnings and notes do not.

| Code | Level | Meaning |
|------|-------|---------|
| E001 | Error | A file has no symbol column |
| E002 | Error | No usable companies were found |
| E003 | Error | The dataset JSON has an unknown version |
| E004 | Error | A file is too large: 25 MB for dataset JSON, 200,000 rows per CSV, 5 MB and 20,000 rows for a snapshot |
| E005, E006, E007 | Error | The JSON is not a dataset or snapshot; the text is not JSON; a statement file has no period column |
| W100 | Warning | Profit before tax minus tax differs from net profit by more than the larger of 1% and ₹1 crore |
| W101 | Warning | The four quarters of a year differ from the annual figure by more than 2% |
| W102 | Warning | Cash and bank ≤ total current assets ≤ total assets does not hold |
| W103 | Warning | Promoter, FII and DII holdings add up to more than 100.5% |
| W104 | Warning | Negative revenue, inventories, receivables or capital expenditure |
| W105 | Warning | The units look wrong: median revenue above 1,00,00,000 (figures probably in ₹ or lakh); every holding percentage at or below 1 (fractions); shares above 1,00,000 crore (a plain count); dividend per share above the price |
| W106 | Warning | The statement basis changes between years |
| W107 | Warning | A fiscal year and its period end disagree |
| W108 | Note | A year is missing between two others |
| W109 | Note | A lender has fields that apply to non-financial companies |
| W110 | Warning | The ISIN does not match the usual format |
| W111–W121 | Warning | Unreadable numbers, unknown columns, duplicates (the later row wins), unknown symbols, dropped old periods, unreadable dates or values, rows without a symbol |
| I001 | Note | The company type will be inferred from the sector |

Older periods beyond 20 years, 16 quarters or 16 shareholding quarters are dropped with a warning.

## Where the data is kept

The imported dataset is saved in your browser's IndexedDB. If that is unavailable, it is saved in
local storage when it is 2 MB or smaller. Otherwise it is kept for this session only, and the banner
offers a JSON export so you can keep a copy. **Use sample data** removes every saved copy.

An import saved by an earlier version of Funda Scanner (the one-row format) is moved to the new
storage once, the first time the app starts; the old copy is removed only after the new one is saved.

## For developers

Implement `DataProvider.getDataset()` (see `src/lib/contracts/provider.ts`) and call
`setDataProvider()` at start-up. A provider with only the older `getUniverse()` still works and is
treated as a snapshot.
